# Canonical bank profile retrieval

CompanyService owns immutable `CompanyBankProfile` snapshots, independently of operational company membership or a documentary `CompanyProfile`. ContextService only mirrors their typed read contract. It never creates snapshots on GET, derives a company name/creator, or reads current operational fields to fill historical `asOf` queries.

The snapshot has `companyId`, `revisionId`, `knownAt`, `bankData`, `sourceId=company-bank-profile`, exact Context material `sourceRefs`, and acquisition `provenance`. `bankData` retains all 23 nullable source fields after the external `SYNTHETIC_U` identifier is mapped to the application's company UUID. Raw flags, codes, worker gradations, and `revenueCompany` strings retain their values and precision. No currency, period, documentary exposure, supplier relation, or payment fact is inferred. Numeric `mainOkvedCode` remains separate from the operational A–U industry sections. Company `region`/`city` are not a person's service geography.

The search projection reads all owner versions from `GET /company-service/internal/bank-profiles/versions?limit=100&after=...`, following opaque string cursors with cancellation and progress checks. Each revision has an independent `bank-profile` stable key and `kind=bank_profile`, separate from documentary `kind=profile`. Its raw geographic, main OKVED, and other declared fields become lexical/dense search text. Global recipient search considers both profile kinds; no region/city filter excludes a company. A bank-profile hit is checked against the latest owner snapshot visible through `GET /company-service/internal/bank-profiles/{companyId}?asOf=...`, including company, revision, source marker, hash, and knowledge time. An older or future snapshot cannot replace the visible owner revision.

Context material chunks for the exact snapshot remain ordinary scoped company materials. Global recipient search only considers profile entries, so those chunks do not add a second recipient authority. Downstream reasoning must retain the `company-bank-profile` source marker and enforce its distinction from documentary exposure; Context performs no economic-object or financial inference. Existing public material DTOs and legacy knowledge contracts remain unchanged. The companion CompanyService bank-profile endpoints must be present before enabling this Context version; upstream failures do not become empty results.

Native model-free regression tests cover raw nullable contracts and provenance, pagination progress, explicit historical reads, and regional lexical relevance where a mismatch remains a candidate. User-role framing is consumed directly from UserService by AgentService, so Context adds no unused User client, role store, or ACL derivation. Tests require no live model or separate database stack.
